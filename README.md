# FastCorr Website

Marketing site for FastCorr — legal correspondent and messenger platform for South African law firms.

## Local preview

```bash
python3 -m http.server 8765
```

Open http://localhost:8765

## GitHub Pages

1. In the repo: **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / folder: `/ (root)`
4. Save — the live URL will be:
   `https://fastcorr-pty-ltd.github.io/fastcorr-website/`

If you later add a custom domain (e.g. `www.fastcorr.co.za`), set it under **Pages → Custom domain**.
